# Ticket Queue System in C++

A console-based ticket queue management system implemented in C++ using Object-Oriented Programming and the Queue data structure.

## Description

The system simulates a real-world queue where customers receive tickets and are served in First-In-First-Out (FIFO) order.

Each ticket contains:

- Ticket Number
- Issue Time
- Waiting Clients
- Expected Service Time

## Features

- Issue new tickets
- Serve the next client
- Display queue information
- Show waiting clients
- Print all issued tickets
- Display queue from left-to-right and right-to-left

## Technologies

- C++
- Object-Oriented Programming (OOP)
- STL Queue
- STL Stack

## Learning Objectives

- Queue (FIFO)
- Queue traversal
- Nested classes
- Object-oriented design
- Queue simulation
